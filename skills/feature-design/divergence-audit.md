# Divergence audit

Read this when step 1 finds that work implementing the declaration has already merged or is in flight, so the code has caught up with the declaration.

The grounding table stays complete: disagreements are only findable by grounding everything, so step 3 runs in full and never stops at the suspected rows. The findings report carries only where code and declaration disagree; it does not restate what the implementation satisfied. The run ends at that report, because the stale record is `document`'s to bring current and there is no design left to hand off.
